# Live dashboard checks — isolated Host instance (same profile 121)

Purpose: verify the Web half and the rendered board in a real browser, without
touching the user's running Desktop generation. An independent Host was booted
from the same profile (`dsh --profile 121 --port 4399 --no-open`), a fixture
board was seeded for one session, and the app was driven in a Chromium page.

```json
{

  "url": "plugins/??@local/dsh-agent-team-workflow/client.js&rev=3a2febd577dc",
  "rev": "3a2febd577dc",
```

(the Desktop generation additionally loads two more shipped bundles).

## 4. Rendered board (seeded fixture from the real finalized run)

Flow panel: 第 1 波 with cards `W1 已批准 / impl-hello / 评审 1/2` and
`W2 已批准 / impl-docs / 评审 1/2`, each with the `R1/2` review self-loop arc and

`Lead → 成员`, `成员 → 工作项`, `评审 → 被审项`.

## 6. Scrollport reset (bug found live, fixed, re-verified)

The View switcher reuses the conversation scrollport. With the chat scrolled to
the bottom (scrollTop = 6093 px), switching to 团队看板 used to mount the board
at the same offset (board rect y = -1038): the panel looked blank until scrolled.

After the fix (`rootRef` + reset the nearest scrollable ancestor on mount):

```json
{ "beforeSwitchScrollTop": 6093, "afterSwitchScrollTop": 0,
  "boardTop": 76, "visible": true }
```
